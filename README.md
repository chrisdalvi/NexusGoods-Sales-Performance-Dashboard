## 📌 Project Overview
This project involves building an interactive Power BI dashboard using an e-commerce dataset to analyze business performance. The dashboard provides insights into sales trends, customer behavior, delivery delays, payment methods, and overall operational efficiency.

## 🎯 What I Did
- Designed and developed a single-page interactive dashboard in Power BI
- Created KPI metrics such as Total Revenue, Total Orders, Average Rating, and Delivery Delay
- Used DAX to calculate measures and derive business metrics
- Implemented slicers and drill-through functionality for detailed analysis
- Built multiple visualizations to represent sales trends and operational performance

## 🛠️ Technologies Used
- Power BI
- DAX (Data Analysis Expressions)

## 🔄 Steps Performed
1. Data Preparation  
   - Imported dataset and performed cleaning and transformation  

2. Data Modeling  
   - Created relationships between tables  
   - Structured data for efficient analysis  

3. DAX Calculations  
   - Developed measures for revenue, orders, ratings, and delays  

4. Dashboard Development  
   - Built KPI cards for quick insights  
   - Created charts for category-wise, state-wise, and time-based analysis  
   - Added slicers for dynamic filtering  
   - Implemented drill-through pages for detailed exploration  

## 📊 End Result
- Identified top-performing product categories and regions  
- Highlighted delivery delays and operational inefficiencies  
- Analyzed customer payment preferences and satisfaction levels  
- Provided a complete, interactive view of business performance to support decision-making
